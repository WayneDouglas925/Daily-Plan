
# Identity-2026: The Re-Build

## Vision
A high-end, dark-mode wellness application that gamifies biological consistency. The app uses "Identity Equity" as its primary currency, rewarding alignment with circadian and metabolic windows.

## Core Features
- **Identity Orb**: A central 3D-looking visualization representing the user's current "Equity" status.
- **Equity Logic**: Tracks current equity, peak high-water mark, and resulting debt.
- **Circadian Sync**: Calculates kitchen closure times based on target sleep and provides rewards/taxes for window adherence.
- **System Modes**: Toggles between OMAD (One Meal A Day) and ADF (Alternate Day Fasting) protocols.
- **Persistence**: Full local storage persistence for all user states.

## Tech Stack
- **React 18+ (TypeScript)**
- **Tailwind CSS**: For high-end styling and glassmorphism.
- **Framer Motion**: For the Identity Orb pulse and particle system.
- **Lucide React**: For premium iconography.

## Design System
- **Colors**: Deep Indigo (#0a0a2e), Neon Green (Success), Neon Amber (Debt/Warning).
- **Effects**: Glassmorphism (backdrop-blur-md), radial gradients, and drifting particles.
- **Typography**: Clean, sans-serif high-end typography.
